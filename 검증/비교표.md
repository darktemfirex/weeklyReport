# 검증 케이스 비교표

| 케이스 | 기대 동작 | 결과 |
|---|---|---|
| 정상 생성 | 이월 1건+신규 1건으로 승인 시 hwpx 저장 | 통과<br>직전보고 읽기 -> 주차 계산 -> 이월 후보 -> 사용자 확인 -> 초안 -> AI 점검 -> 계속 표시 -> 검증 -> 사용자 승인 -> 저장 |
| 입력에 없는 숫자 | 규칙1 위반 3회 시 사람 이관, 저장 없음 | 통과<br>직전보고 읽기 -> 주차 계산 -> 이월 후보 -> 사용자 확인 -> 초안 -> AI 점검 -> 계속 표시 -> 검증 -> 초안 -> AI 점검 -> 계속 표시 -> 검증 -> 초안 -> AI 점검 -> 계속 표시 -> 검증 -> 사람 전담 |
| 개인정보 입력 | 전화번호는 가려서 저장, 로그·산출물에 원문 없음 | 통과<br>직전보고 읽기 -> 주차 계산 -> 이월 후보 -> 사용자 확인 -> 초안 -> AI 점검 -> 계속 표시 -> 검증 -> 사용자 승인 -> 저장 |
| 반려 2회 | 반려하면 내용 입력으로 돌아가고, 두 번째 반려에서 사람 이관 | 통과<br>직전보고 읽기 -> 주차 계산 -> 이월 후보 -> 사용자 확인 -> 초안 -> AI 점검 -> 계속 표시 -> 검증 -> 사용자 승인 -> 사용자 확인 -> 초안 -> AI 점검 -> 계속 표시 -> 검증 -> 사용자 승인 -> 사람 전담 |
| 금주 칸 0건 | 금주가 비어도 유효한 hwpx 저장 | 통과<br>직전보고 읽기 -> 주차 계산 -> 이월 후보 -> 사용자 확인 -> 초안 -> AI 점검 -> 계속 표시 -> 검증 -> 사용자 승인 -> 저장 |
| 기존 파일 덮어쓰기 거부 | 덮어쓰기 동의 없으면 저장 안 함, 기존 파일 유지 | 통과<br>직전보고 읽기 -> 주차 계산 -> 이월 후보 -> 사용자 확인 -> 초안 -> AI 점검 -> 계속 표시 -> 검증 -> 사용자 승인 -> 저장 |
| 건수 부족(5건 미만) | 금주+차주 5건 미만이면 신규 건을 다시 받고, 채우면 저장 | 통과<br>직전보고 읽기 -> 주차 계산 -> 이월 후보 -> 사용자 확인 -> 초안 -> AI 점검 -> 계속 표시 -> 검증 -> 사용자 승인 -> 저장 |
| 샘플 3개 골든 | 샘플을 파싱→렌더→파싱하면 같은 보고서 | 통과<br>파싱 → 렌더 → 파싱 |
